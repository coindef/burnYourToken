1从 Claude 用量页抄三个数

  1. Claude
  2. Settings
  3. Usage

英文界面上一般就这三个词。别的产品这里的名字可能稍有不同。这一页不会自己去读用量。

  • ①5 小时额度 Session：这一小段用了百分之几，或还剩百分之几。
  • ②何时重置 Resets in：这段还要多久结束。还没开始用、页面没写时间，可以先空着。
  • ③每周额度 Weekly：这一周用了百分之几，以及周几、几点重置。

用量页只给你看用了百分之几、什么时候重置，不公布 token 数。大、中、小是经验规则，不是厂商给的数字。

已带回你在这个标签页里填过的内容。重置时间可能已经变了，对照用量页确认后，再点「算一下」。

按 API 用量付钱没有「窗口」，用量页上没有这三个百分比，这个工具不适用。

档位是怎么算的？（经验规则）
  1. 5 小时额度还剩多少、每周额度还剩多少，取少的那个，叫「有效剩余」。
  2. 大档：两个都剩 50% 以上（不含 50%），并且离每周额度重置还有 1 天以上。
  3. 中档：有一个剩 20%–50%。两个都剩 50% 以上、但每周额度 1 天内就重置的，也只算中档。
  4. 小档：有一个剩不到 20%，或者离每周额度重置只剩几小时（不到 5 小时）。
  5. 同时符合两条的，按小的那个算，不会往大了算。剩 0 → 先别开新项目，等重置。
  6. 5 小时额度本来就几个小时重置一次，它的重置时间不影响档位；只是卡在它上面、它又快重置时，会提醒你重置后再算一次。
  7. 小档：大约 15–30 分钟，聊几轮就够。中档：大约 1 小时，来回聊十几轮。大档：大约 2–3 小时，可以分几次做完。
  8. 只看百分比，不看你订的是哪一档。同样剩 50%，贵的档能做的事更多，但具体多多少厂商没公布，我们也不假装知道。
